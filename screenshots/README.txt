This directory is for storing screenshots of the Team Kanya Raasi application.

To add screenshots:
1. Take screenshots of your running application
   - Windows: use Win+Shift+S
   - Mac: use Cmd+Shift+4
2. Save them in this directory with the following suggested names:
   - home-page.png - Screenshot of the home page
   - team-list.png - Screenshot of the team members list
   - member-details.png - Screenshot of a specific member's details
   - add-member.png - Screenshot of the add member form

After adding screenshots, commit and push them to GitHub to update the README.md display.
